1. Для кого предназначено приложение

Hermes — личная интеграция на базе Hermes Agent для работы владельца со своим аккаунтом Google. Она не предоставляет регистрацию сторонним пользователям. Управление выполняется из экземпляра Hermes и настроенного владельцем чата.

Это не сервис Google. Данная страница не является интерфейсом входа и не запрашивает пароль, коды подтверждения или файлы доступа.

2. Какие данные доступны и зачем

Доступ ограничивается разрешениями, выданными владельцем на странице Google, его правами на конкретные ресурсы и задачей, которую он поручил помощнице.

  • Почта: сведения о письмах и их содержимое — для поиска, чтения, подготовки и отправки сообщений, работы с метками и состоянием писем.
  • Календарь: названия календарей, события, даты, время и другие сведения события — для расписания и порученных изменений.
  • Контакты: имена и контактные сведения — для поиска нужного человека. В текущей настройке доступно только чтение.
  • Диск: метаданные и содержимое доступных файлов — для поиска, чтения, загрузки и порученной организации файлов.
  • Документы и таблицы: содержимое и структура нужных документов — для чтения, создания и редактирования по поручению.
  • Технические сведения: идентификаторы ресурсов, результаты команд и сведения об ошибках — для выполнения задачи и проверки результата.

Разрешение само по себе не означает публикацию данных в интернете. Помощница настроена получать явное подтверждение владельца перед отправкой сообщений и изменениями его данных.

3. Ограничение использования

Назначение обработки — выполнять явно порученные владельцем задачи и возвращать ему результаты. Эта интеграция не предназначена для рекламы, продажи данных или создания общедоступной базы писем, контактов и файлов.

Использование информации, полученной через Google API, должно соответствовать Google API Services User Data Policy, включая требования Limited Use. Данные Google не должны использоваться для обучения обобщённых моделей искусственного интеллекта.

Текущая настройка: 10 ноября 2026 года проверено совпадение аккаунта OpenAI, используемого Hermes, с открытым аккаунтом ChatGPT. Переключатель «Помогите улучшить модель для всех» выключен; состояние подтверждено после обновления страницы. Согласно документации OpenAI, это исключает использование новых обычных чатов и задач Codex для обучения моделей. Это не означает отсутствия обработки или хранения на стороне поставщика и не удаляет ранее сохранённые сведения.

У Codex существует отдельная настройка Include environments для обучения на дополнительных данных облачных сред. Эта локальная интеграция не использует облачные среды Codex для обработки данных Google; проверка основного переключателя не выдаётся за изменение этой отдельной настройки. Данные Google не следует включать в отзывы поставщику или передавать через режимы, допускающие обучение обобщённых моделей. При смене аккаунта, поставщика или способа обработки режим нужно проверить заново.

4. Кому может передаваться информация

Нельзя утверждать, что все сведения всегда остаются только на компьютере. Для работы этой настройки могут участвовать следующие сервисы:

  • Google: авторизация и выполнение запросов к почте, календарю, контактам, документам и файлам.
  • OpenAI: в текущей настройке формирует ответы помощницы. Данные, включённые в запрос к модели — сообщения, выбранная история и результаты инструментов, — могут передаваться этому сервису для обработки задачи. Это не означает автоматическую отправку всего аккаунта Google.
  • Telegram: команды и ответы проходят через настроенный чат. Если результат содержит сведения из аккаунта Google, эта часть результата также передаётся через Telegram.

Хранение и обработка на стороне сторонних сервисов зависят от их условий и настроек аккаунтов. Эта политика не обещает отсутствие хранения, просмотра или иной обработки у этих поставщиков. Отключение обучения не является режимом нулевого хранения. При изменении поставщика или настроек нужно повторно проверить допустимость передачи данных до их дальнейшей обработки.

5. Локальные файлы доступа и история

Файлы разрешения доступа сохраняются на компьютере владельца и используются локальным экземпляром Hermes. Они не включены в код или содержимое этого сайта. Защита компьютера и резервных копий остаётся отдельной задачей владельца.

Hermes может сохранять историю диалогов, вызовы инструментов и результаты в своей локальной истории и журналах. Если в результат попали сведения из Google, они могут остаться в этой истории. Режим хранения у поставщика модели и в Telegram регулируется отдельно.

6. Срок хранения, отзыв и удаление

Срок хранения зависит от настроек истории, журналов, резервных копий и участвующих сервисов. Этот сайт не устанавливает и не обещает автоматическое удаление всей истории через фиксированное число дней.

  1. Чтобы остановить дальнейший доступ, владелец может отозвать разрешение для приложения в подключениях аккаунта Google.
  2. Отзыв разрешения не удаляет ранее сохранённые диалоги, результаты команд или резервные копии. Для их удаления нужны отдельные действия в Hermes и используемых хранилищах.
  3. Удаление или управление данными на стороне OpenAI и Telegram выполняется через возможности этих сервисов. Удаление локального файла само по себе не стирает внешние копии.

7. Посещение информационного сайта

На этих двух страницах нет форм, встроенной аналитики, рекламных блоков или исполняемых сценариев. Код страниц не устанавливает файлы cookie и не получает письма, контакты, документы или файлы доступа.

Размещение — GitHub Pages. Сам хостинг может обрабатывать технические данные посетителей. В частности, GitHub сообщает о записи IP-адресов посетителей в целях безопасности. Это обработка хостинга, а не выгрузка содержимого аккаунта Google на сайт.

8. Изменения и управление владельцем

При изменении назначения приложения, запрашиваемых разрешений или получателей данных текст должен быть обновлён, а изменения — согласованы с владельцем. Эта политика не заменяет подтверждение конкретного поручения и согласие на странице Google.

Владелец управляет личным экземпляром Hermes и может запросить проверку разрешений, отключение интеграции или инструкции по удалению истории через свой настроенный чат. Приложение не объявлено открытым для обращений сторонних пользователей.
